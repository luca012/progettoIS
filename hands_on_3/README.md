# Diagrams description:

* class_diagram.png: this diagram shows the main classes of the authentication library together with their attributes and methods, and the relationships between the user interface, library, database connector and user.
* state_machine_diagram.png: this diagrams describes transitions between the logged-out, logged-in and password-recovery states, including authentication, logout and inactivity timeout.
* sequence_diagram.png: this diagram shows the interactions between the user, interface, library and database during login, administrative operations and password recovery, also including repeated login attempts.
* activity_diagram.png: this diagram describes the overall workflow of authentication, password recovery and administrative operations, also showing decisions, retries, account blocking and session termination.
