# Project structure:

- **hands_on_1/**: agile activities report and Java authentication library, including source code, tests, and SQLite database.
- **hands_on_2/**: SRS materials in word and PDF formats.
- **hands_on_3/**: UML class, sequence, state machine, and activity diagrams in PNG format, with a README file that briefly explain the contents.
- **hands_on_4/**: code-quality analysis organized into `before/` and `after/`, containing C source code, CSV metrics, MISRA reports, and LCOV coverage results.
- **hands_on_5/**: Authentication microservice controller (`AuthController.java`) and a README describing the changes made.
